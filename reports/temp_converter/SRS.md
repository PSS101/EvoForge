Title: Temperature Converter Utility
Version: 1.0
Introduction: This document outlines a simple Python utility designed to convert temperatures between Celsius and Fahrenheit.
Functional Requirements:
- The program should accept input in either Celsius or Fahrenheit.
- It must accurately convert the selected temperature type into the other.
- The output should be displayed with two decimal places for precision.
Non-Functional Requirements: None
System Scope/Flow: The utility will run on a Windows environment and can handle conversions between any valid temperature inputs.
