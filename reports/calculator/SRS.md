Title: Simple Calculator Command-Line Utility
Version: 1.0
Introduction: This document outlines the requirements for a simple command-line calculator in Python that can perform basic arithmetic operations (addition, subtraction, multiplication, division) and display the result.
Functional Requirements:
- The program should accept input from the user through the command line interface.
- It must support addition (+), subtraction (-), multiplication (*), and division (/).
- The output should be displayed on the console with appropriate formatting (e.g., floating point for division results).
Non-Functional Requirements: None
System Scope/Flow:
1. Accept input from user through command line.
2. Perform arithmetic operations based on user's choice.
3. Display result on console.
