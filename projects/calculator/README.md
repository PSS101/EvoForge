# Simple Calculator Utility

A modular command-line calculator written in Python. It supports basic arithmetic operations.

## Features
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Error handling for division by zero

## Running the App
Run the entry point script using:
```bash
python main.py
```

## Running Tests
Run the pytest suite:
```bash
pytest tests/
```
